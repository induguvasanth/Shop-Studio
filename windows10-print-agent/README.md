# Windows 10 Print Agent (experimental)
Install Python 3.11+, Canon G3012 and Brother DCP-L2541DW drivers, and SumatraPDF. Verify printer names in Windows Settings > Printers & scanners. Copy config.example.json to config.json and set the Apps Script URL and agent secret. Start with START-AGENT.cmd. dry_run=true claims a job and marks it failed for testing; it DOES NOT print. Set dry_run=false only after testing with non-sensitive documents. The agent submits to the Windows spooler but cannot prove physical completion, paper size enforcement, color fidelity, or duplex. Claimed jobs do not auto-retry to avoid duplicates. Never put config.json in GitHub.
